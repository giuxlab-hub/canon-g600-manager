## Repository-specific additions

- `README.md`: English/Italian repository documentation.
- `LICENSE`: complete GNU General Public License version 3 text, reflecting the original program's `GPL-3.0-or-later` declaration.
- `packaging/`: original `.desktop` launcher, SVG icon and Debian control metadata extracted from the shipped `.deb`.
- `.gitignore`: local build and editor artifacts.
- `build-deb.sh` in the initial v0.1.0 import: the **only edit** to the expanded build script changed the output from a fixed `/home/giu/canon-g600-manager_0.1.0_all.deb` to `./canon-g600-manager_0.1.0_all.deb`. The source tarball attached to the release retains the original build script exactly.

In the initial v0.1.0 import, no application logic was modified. The default printer queue and local-network address remain as shipped; users can edit both in the GUI. No credentials, session data or user's configuration directories are part of the source tree or release.

The `__pycache__` directory from the expanded working folder is deliberately not versioned: it is interpreter-generated bytecode and is not source.

## Validation scope

- Matched the original Python application byte-for-byte across expanded source, original source tarball and Debian payload.
- Inspected Debian package metadata, installed paths and declared dependencies.
- Compiled the Python script in memory to check Python syntax without starting GTK or touching a printer.
- A local `dpkg-deb` build checks packaging; it is not a physical printer, scanner or GUI acceptance test.

The original distribution packages are attached to the [v0.1.0 release](https://github.com/giuxlab-hub/canon-g600-manager/releases/tag/v0.1.0), without repacking or normalization.

## Imported version 0.2.0

The author supplied two additional original artifacts: `canon-g600-manager_0.2.0_all.deb` (SHA-256 `ccf55edc52688d4b7f6c57c52d5c02cfe3828a851bcf0428e344d7bbbab6a051`) and `canon-g600-manager-source_0.2.0.tar.gz` (SHA-256 `68facebdfd48decac5a464d9daa3e857ca0886a884e00cad9914005cd03ba205`). Version 0.2.0 introduces English localization and interactive language switching, but its installed script lacks `#!/usr/bin/python3`. Original packages are preserved; the next corrective release restores direct invocation.

## v0.2.1 corrective GitHub distribution

The historical original author packages v0.2.0 are preserved byte-for-byte in the v0.2.0 pre-release. The v0.2.1 source changes only the interpreter shebang/SPDX header, unlocalized maintenance/print-result strings and Debian build version/output path. The application logic remains built on the author-provided bilingual v0.2.0 code. The Debian 0.2.1 package and source tarball are rebuilt locally from this reviewed GitHub state.
